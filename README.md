# RiyaMaga

**Smarter Logistics. Every Mile Connected.**

RiyaMaga is a multi-tenant logistics and operations management SaaS
designed to help delivery businesses manage shipments, drivers,
vehicles and delivery operations.

## Technology Stack

- Frontend: Next.js, React, TypeScript
- Backend: NestJS, Node.js, TypeScript
- Database: PostgreSQL
- ORM: Drizzle ORM
- Package management: pnpm
- Infrastructure: AWS CDK
- Testing: Jest, Supertest, Playwright
- Containers: Docker

## Repository Structure

- apps/web - Next.js frontend
- apps/api - NestJS backend
- apps/worker - Background processing
- packages/database - Database schema and access
- packages/shared - Shared utilities and types
- packages/validation - Shared validation schemas
- infrastructure/aws - AWS infrastructure
- docs - Architecture and technical decisions
